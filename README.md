# WebStudio — личная офлайн-IDE

Браузерная IDE для создания сайтов: файловый менеджер слева, редактор CodeMirror и предпросмотр сайта в одной рабочей области справа.

## Просто открыть, без сервера и установки

1. Скачайте архив репозитория (**Code → Download ZIP**) и распакуйте его. Не открывайте HTML прямо из просмотра GitHub или из окна архива.
2. **Дважды щёлкните по [WebStudio.html](WebStudio.html)** в корне распакованной папки. Рекомендуется Chrome или Edge.
3. Создайте проект или откройте демо. Интернет, аккаунт, `npm` и сервер для работы не нужны.

`WebStudio.html` — готовое автономное приложение: JavaScript, CSS, шрифты, CodeMirror и JSZip уже встроены внутрь одного файла. Исходный `index.html` предназначен **только для разработки через Vite**; для двойного щелчка нужен именно `WebStudio.html`.

Проекты сохраняются в IndexedDB **на этом компьютере в том браузере, которым открыт файл**. Другой браузер или очищенные данные браузера не увидят эти проекты. Регулярно экспортируйте важные проекты в ZIP: это переносимая резервная копия. Если браузер запрещает IndexedDB для локальных файлов, приложение покажет ошибку сохранения — используйте Chrome/Edge и экспортируйте ZIP. Сам файл приложения можно скопировать другим людям; он не содержит ваших проектов или пароля. Чтобы им пользовались только вы, храните его в своей учётной записи компьютера с обычными правами доступа к файлам.

## Возможности

- Несколько проектов, автосохранение в IndexedDB, восстановление после перезагрузки и `Ctrl+S` для немедленного сохранения.
- Создание, открытие, переименование, удаление, поиск и перемещение файлов и папок; вкладки, сворачивание дерева, изменение ширины и скрытие проводника.
- CodeMirror 6: подсветка HTML, CSS, JavaScript/TypeScript, JSON, XML/SVG и Markdown, нумерация строк, поиск по коду (`Ctrl+F`), отмена/повтор (`Ctrl+Z`/`Ctrl+Y`).
- PNG и другие изображения, MP3 и другие аудиофайлы хранятся как бинарные файлы; миниатюры, размеры, длительность и аудиоплеер.
- Автообновляемый предпросмотр в `iframe sandbox="allow-scripts"` с локальными относительными путями к HTML, CSS, JS, изображениям и аудио; ручное обновление и полноэкранный режим.
- Импорт файлов, папок (`webkitdirectory`) и ZIP; экспорт всего проекта в ZIP с сохранением папок, скачивание отдельных файлов.
- Стартовый экран с готовым демо-проектом Aurora.

Внешние ссылки, которые **вы сами** добавите в создаваемый сайт, могут обращаться в интернет. Сам WebStudio не требует внешних API/CDN и не отправляет ваши проекты на сервер.

## Разработка и пересборка автономного файла

Для изменений в исходном коде нужны Node.js и npm:

```bash
npm ci
npm run dev             # среда разработки на localhost
npm run build:offline   # обновить готовый WebStudio.html в корне
npm test                # проверки логики файлов, ZIP, preview и IndexedDB
```

`npm run build` создаёт обычный `dist/` для статического хостинга (не нужен для личного офлайн-использования). `npm run build:offline` создаёт один HTML-файл для двойного щелчка. `localhost` при разработке — это ваш компьютер, не публикация в интернете.

## Структура

```text
Webstudio/
├── WebStudio.html           # Готовое автономное приложение: открыть двойным щелчком
├── offline-source.html      # HTML-шаблон офлайн-сборки (не открывать отдельно)
├── index.html               # HTML-шаблон для разработки через Vite
├── src/
│   ├── main.jsx             # Точка входа React
│   ├── App.jsx              # Интерфейс и действия
│   ├── CodeEditor.jsx       # Редактор CodeMirror
│   ├── project.js           # Дерево файлов, IndexedDB, ZIP и демо
│   ├── preview.js           # Изолированный предпросмотр ресурсов
│   └── styles.css           # Тёмный интерфейс
├── scripts/copy-offline.mjs # Помещает офлайн-сборку в корень проекта
├── tests/project.test.js    # Проверки логики приложения
├── vite.config.js           # Обычная и автономная конфигурации сборки
└── package.json
```
