# WebStudio

Браузерная IDE для создания сайтов. Две основные панели: проводник проекта и единая рабочая область, переключаемая между редактором и предпросмотром. Сервер и платные API не требуются: после сборки приложение работает как статический сайт.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, показанный Vite (по умолчанию `http://localhost:5173`). Для статической сборки: `npm run build`; для проверки: `npm test`. Собранный `dist/` можно разместить на любом статическом хостинге. Зависимости CodeMirror и JSZip собираются вместе с приложением — CDN не нужен. Шрифты имеют системные fallback-варианты.

## Возможности

- Создание нескольких проектов; автоматическое сохранение файлов и бинарных Blob в IndexedDB; восстановление после перезагрузки. `Ctrl+S` сохраняет немедленно. Список проектов доступен через шапку приложения.
- Дерево файлов: создание, открытие, переименование, удаление, сворачивание папок, поиск, перемещение перетаскиванием на папку или в корень. Левая панель изменяет ширину перетаскиванием и скрывается.
- CodeMirror 6: подсветка HTML, CSS, JS/TS, JSON, XML/SVG и Markdown; строки, автоотступы, поиск (`Ctrl+F`), история (`Ctrl+Z`/`Ctrl+Y`), вкладки. Остальные текстовые файлы открываются как обычный текст.
- PNG и другие изображения, MP3 и другие аудиофайлы хранятся без преобразования. Миниатюры, размеры изображения, размер файла, длительность и встроенный аудиоплеер.
- Предпросмотр в `iframe sandbox="allow-scripts"`: пути к локальным изображениям, аудио, CSS и JS пересобираются в безопасные временные Blob URL; в CSS разрешаются относительные `url(...)` и `@import`. Автообновление после правок, ручное обновление, полноэкранный режим и переходы между HTML-страницами проекта. У iframe нет `allow-same-origin`, поэтому код сайта не может обращаться к хранилищу или DOM IDE.
- Импорт файлов, целых папок (`webkitdirectory`) и ZIP; экспорт ZIP с сохранением структуры и скачивание отдельных файлов. ZIP с единственной корневой папкой при открытии становится проектом с её именем. Вредоносные пути `..` игнорируются.
- Стартовый экран, демо-проект Aurora, уведомления, индикатор сохранения.

## Структура

```text
Webstudio/
├── index.html                 # Точка входа
├── public/favicon.svg          # Иконка вкладки
├── src/
│   ├── main.jsx               # Инициализация React
│   ├── App.jsx                # Интерфейс и действия пользователя
│   ├── CodeEditor.jsx         # CodeMirror и история для вкладок
│   ├── project.js             # Файловое дерево, IndexedDB, ZIP и демо
│   ├── preview.js             # Изолированный предпросмотр и пути ресурсов
│   └── styles.css             # Адаптивная тёмная тема
├── tests/project.test.js      # Проверки файлов, ZIP, медиа, preview и IndexedDB
├── vite.config.js             # Сборка и настройка локального предпросмотра
└── package.json
```

Данные проектов находятся только в IndexedDB данного браузера/домена. Регулярно экспортируйте важные проекты в ZIP. Внешние запросы сайта, открытого в iframe, зависят от браузерных ограничений и доступности сети; локальные ресурсы проекта работают без сервера. Режим импорта папок требует браузера с поддержкой `webkitdirectory` (Chrome, Edge и большинство браузеров на Chromium).
